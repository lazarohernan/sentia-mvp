# Ilustraciones Perks

Originales SVG editables, compatibles con Affinity. Copias de uso web en `public/images/illustrations/`.

- `perks-empty-attention-v1.svg`: bandeja de seguimiento sin pendientes.
- `perks-empty-opinions-v1.svg`: conversaciones por empezar.
- `perks-empty-reports-v1.svg`: hoja de resumen para informes sin datos suficientes.
- `perks-empty-improvements-v1.svg`: lista de acciones por definir para planes vacíos.
- `perks-empty-analytics-v1.svg`: panel y conversación para analíticas sin evaluaciones.
- `perks-empty-coaching-v1.svg`: dos conversaciones para coaching sin evaluaciones individuales.
- `perks-empty-notifications-v1.svg`: campana en reposo para notificaciones vacías.

Paleta gris verdoso. Tamaño de uso: 88 px de ancho. Sin animación ni sombras.
En la interfaz son decorativas (`alt=""`): el texto comunica el estado.
Conservar versiones anteriores al crear nuevas variantes y sincronizar la copia web.
